# 📚 Links das minhas disciplinas

Portal simples e elegante para professores organizarem e compartilharem links de materiais didáticos por curso e disciplina.

## ✨ Funcionalidades

- 📂 **Organizado por curso** – Cada curso possui suas disciplinas agrupadas
- 🔗 **Links categorizados** – Pasta Geral, Slides, Conteúdo e Atividades
- 🎨 **Design limpo** – Interface com Tailwind CSS, responsiva e moderna
- ⚡ **Carregamento dinâmico** – Dados carregados via `fetch` a partir de um arquivo JSON
- 🚫 **Indicador visual** – Links ativos (🔗) e bloqueados (🚫)
- 📱 **Responsivo** – Adapta-se a telas grandes e pequenas

## 🛠️ Tecnologias Utilizadas

- **React 18** – Biblioteca para construção da interface
- **Tailwind CSS** – Estilização rápida e utilitária
- **Babel Standalone** – Para transpilar JSX no navegador
- **Fetch API** – Para carregar os dados do arquivo JSON
